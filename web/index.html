四大核心功能

  1. Docker 一键放桌面：自动识别容器，一键在飞牛桌面生成图标。
  2. 局域网/公网服务反向代理：可将内网服务或公网服务代理至本机，并生成桌面图标。
  3. 将任意网页快捷方式放置到飞牛桌面。
  4. 自动读取 Watchcow 配置：兼容 Docker compose 中的 Watchcow 标签配置，一键启用。
