# 把 Docker 放到桌面 (fn-docker-to-desktop)

本项目灵感来源于开源项目 [watchcow](https://github.com/tf4fun/watchcow)。

---

### 三大核心功能

1. **Docker 与端口一键放桌面**：智能识别容器与系统监听端口，一键在飞牛 OS 桌面生成原生应用图标。
2. **外部与局域网服务反向代理**：内置高性能反向代理，可将内网设备或公网服务代理至本机端口并放置桌面。
3. **个性化图标定制与快捷管理**：支持文字图标即时生成、网络图标与本地上传，提供一键启用、停用及编辑管理。

---

### 使用方式

请直接前往 [Releases](https://github.com/67373net/fn-docker-to-desktop/releases) 界面下载最新版本的 `.fpk` 安装包，在飞牛 OS「应用中心 -> 手动安装」中上传即可。
